# 国产云平台

> 华为云 / 魔搭 / 智谱 / 百度千帆 / 阿里百炼

## 平台对比

| 平台 | 链接 | 核心服务 | 特点 |
|------|------|----------|------|
| 华为云 ModelArts | https://support.huaweicloud.com/productdesc-modelarts/modelarts_01_000000.html | 模型训练/部署/推理 | 全栈 AI 平台 |
| 华为云 CodeArts | https://www.huaweicloud.com/product/codearts.html | AI 辅助开发 | DevSecOps + AI |
| 魔搭 ModelScope | https://modelscope.cn/ | 模型/数据集/Demo | 阿里达摩院，社区 |
| 智谱 AI | https://open.bigmodel.cn/ | GLM-4 API + Agent | 模型即服务 |
| 百度千帆 | https://cloud.baidu.com/product/wenxinworkshop | 文心 API + 精调 | 百度生态 |
| 阿里百炼 | https://bailian.console.aliyun.com/ | 通义 API + Agent | 阿里生态 |
| 腾讯混元 | https://cloud.tencent.com/product/hunyuan | 混元大模型 API | 腾讯生态 |
| 火山引擎 | https://www.volcengine.com/product/doubao | 豆包大模型 API | 字节跳动 |

## 使用建议

- **API 调用**：智谱/通义/DeepSeek API 成本远低于 OpenAI
- **合规便利**：国内平台数据不出境，备案齐全
- **中文能力**：国产模型中文理解/生成普遍更强
- **微调服务**：千帆/百炼提供在线微调，无需本地 GPU
