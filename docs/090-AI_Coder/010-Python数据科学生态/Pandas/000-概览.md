# Pandas

> 数据清洗、分组聚合、时间序列

## 核心 API

- `DataFrame` / `Series` — 基本数据结构
- `groupby` + `agg` — 分组聚合
- `merge` / `join` — 表连接
- `pivot_table` — 透视表
- `read_csv` / `read_excel` / `read_json` — 数据读取

## 进阶

- `apply` 性能陷阱与向量化替代方案
- `swifter` 加速 apply
- `pd.eval()` / `pd.query()` — 表达式求值优化
- 大数据处理：`chunksize` 分块 / `Dask` / `Polars`
