# NumPy

> 向量化计算、广播机制、内存布局

## 核心 API

- `np.dot` / `np.matmul` — 矩阵乘法
- `np.einsum` — 爱因斯坦求和约定
- 广播规则 — 不同形状数组运算
- `np.lib.stride_tricks` — 内存视图技巧

## 进阶

- 与 C++ 的 `pybind11` 交互
- ndarray 内存布局（C-order vs Fortran-order）
- 结构化数组与记录数组
