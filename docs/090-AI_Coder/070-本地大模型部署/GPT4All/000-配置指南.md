- GitHub：https://github.com/nomic-ai/gpt4all
- 官网：https://gpt4all.io/
- 语言：C++/Python
- 许可证：MIT

## 系统要求

| 项目 | 最低要求 | 推荐 |
|------|----------|------|
| 操作系统 | Windows 10+ / macOS 12+ / Linux | — |
| 内存 | 8 GB | 16 GB+ |
| CPU | 4 核 | 8 核+，AVX2 支持 |
| 磁盘 | 5 GB | SSD 20 GB+ |

> 💡 GPT4All 主打 CPU 推理，无需 GPU

## Python 使用

### 基本对话

```python
from gpt4all import GPT4All

model = GPT4All("Meta-Llama-3-8B-Instruct.Q4_0.gguf")
response = model.generate("你好，请自我介绍", max_tokens=512)
print(response)
```

### 流式输出

```python
model = GPT4All("Meta-Llama-3-8B-Instruct.Q4_0.gguf")
for chunk in model.generate("你好", max_tokens=512, streaming=True):
    print(chunk, end="", flush=True)
```

### Chat 模式

```python
model = GPT4All("Meta-Llama-3-8B-Instruct.Q4_0.gguf")
with model.chat_session():
    response1 = model.generate("你好")
    response2 = model.generate("请详细介绍一下自己")
```

### Embedding

```python
from gpt4all import Embed4All

embedder = Embed4All()
embedding = embedder.embed("你好世界")
print(len(embedding))  # 768
```
