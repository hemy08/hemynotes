# 工具栏设置菜单

![](images/image.png)

设置菜单包含以下功能：

| 功能 | 说明 |
| --- | --- |
| 系统设置 | 字体、编辑器背景色、自动保存间隔等系统配置 |
| 主题设置 | 23种应用主题 + 55种编辑器主题，支持实时切换 |
| 快速链接设置 | 配置左侧导航栏的快捷应用和链接 |
| 编辑器设置 | Monaco Editor 选项配置（行号、缩进、换行等） |

## 对话框实现

各设置对话框在 `src/main/dialogs/` 目录下：

- `ShowSystemSettingDialog.ts`：系统设置对话框
- `ShowThemeSettingDialog.ts`：主题设置对话框
- `ShowEditorSettingDialog.ts`：编辑器设置对话框
- `ShowQuickLinkSettingDialog.ts`：快速链接设置对话框

## 配置管理

配置使用 `electron-store` 在用户目录下管理，支持多用户独立配置（`.baizenotes` 目录）。配置管理代码在 `src/main/config/` 目录下：

- `config-manager.ts`：配置管理器
- `system-setting.ts`：系统设置
- `theme-config.ts`：主题配置
- `editor-setting.ts`：编辑器设置
- `quick-link-config.ts`：快速链接配置

## 主题系统

项目支持 23 种应用主题和 55 种编辑器主题：

- **应用主题**：白泽紫韵、暖白温馨、清新简约、护眼系列、深色系列等
- **编辑器主题**：Monaco Editor 主题同步，支持实时切换无需重启

主题切换时，主进程通过 `baize-notes:theme-updated` IPC 通道通知所有窗口更新主题样式。
