# 常见错误以及解决方法

## 一、安装相关

### 1.1 electron 安装失败

**问题**：`npm install electron` 时下载失败或超时。

**解决**：
1. 配置淘宝镜像：
```
npm config set electron_mirror=https://npmmirror.com/mirrors/electron/
npm config set electron_builder_binaries_mirror=https://npmmirror.com/mirrors/electron-builder-binaries/
```
2. 手动下载 electron 安装包，放在 `C:\Users\{用户名}\AppData\Local\electron\Cache` 目录下
3. 清理缓存后重试：`npm cache clean -f`

### 1.2 权限问题

**问题**：`npm install` 时报权限错误。

**解决**：
1. 以管理员身份运行命令行
2. 清理缓存：`npm cache clean -f`
3. 删除 `node_modules` 和 `package-lock.json` 后重新安装

### 1.3 node-sass / sqlite3 编译失败

**问题**：原生模块编译失败。

**解决**：
```
npm run rebuild
```

## 二、开发相关

### 2.1 菜单栏不显示

**问题**：应用启动后菜单栏不显示。

**解决**：`BrowserWindow` 配置中 `autoHideMenuBar` 需设置为 `false`。

### 2.2 预览区域不渲染

**问题**：编辑器内容变化但预览区域不更新。

**解决**：
1. 检查 `MarkdownPreviewComponent.vue` 的 `watch` 是否正确监听 `editorContent`
2. 检查 IPC 通信是否正常（`pre-render-monaco-editor-content` 通道）
3. 查看控制台是否有 mermaid/katex 渲染错误

### 2.3 Mermaid 渲染失败

**问题**：Mermaid 代码块显示为错误或空白。

**解决**：
1. 检查 Mermaid 语法是否正确
2. 查看 console 中的 mermaid 错误信息
3. 确认 `resources/mermaid` 资源文件已正确打包

### 2.4 Monaco Editor 加载缓慢

**问题**：首次加载 Monaco Editor 较慢。

**解决**：Monaco Editor 体积较大，首次加载需要初始化 worker，属于正常现象。生产环境打包后会有所改善。

## 三、打包相关

### 3.1 打包后资源文件缺失

**问题**：打包后主题、图标等资源文件找不到。

**解决**：检查 `electron-builder.yml` 的 `extraResources` 配置，确保资源文件正确包含。

### 3.2 打包体积过大

**问题**：安装包体积过大。

**解决**：
1. 检查 `files` 配置，排除不必要的文件
2. 使用 `!out/renderer/src/**` 排除渲染进程源码
3. 考虑使用 `nsis` 压缩选项
