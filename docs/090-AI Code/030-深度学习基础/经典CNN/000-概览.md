# 经典 CNN

> LeNet → AlexNet → VGG → GoogLeNet → ResNet → EfficientNet

## 架构演进

| 模型 | 年份 | 核心创新 | 论文 |
|------|------|----------|------|
| LeNet-5 | 1998 | 卷积+池化开山之作 | — |
| AlexNet | 2012 | ReLU / Dropout / 数据增强 | [NeurIPS 2012](https://papers.nips.cc/paper/2012/hash/c399862d3b9d6b76c8436e924a68c45b-Abstract.html) |
| VGGNet | 2014 | 小卷积核堆叠 (3×3) | [arXiv:1409.1556](https://arxiv.org/abs/1409.1556) |
| GoogLeNet | 2014 | Inception 模块 (多尺度) | [arXiv:1409.4842](https://arxiv.org/abs/1409.4842) |
| ResNet | 2015 | **残差连接**（最重要的创新） | [arXiv:1512.03385](https://arxiv.org/abs/1512.03385) |
| DenseNet | 2017 | 密集连接 | [arXiv:1608.06993](https://arxiv.org/abs/1608.06993) |
| EfficientNet | 2019 | 复合缩放 | [arXiv:1905.11946](https://arxiv.org/abs/1905.11946) |

## 重点：ResNet 残差连接

- $y = F(x) + x$ — 恒等映射捷径
- 解决深层网络退化问题
- 理解 Pre-Activation ResNet
