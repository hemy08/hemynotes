# Prompt 工程

> Zero-shot / Few-shot / CoT / 结构化 Prompt

## Prompt 设计模式

| 模式 | 说明 | 示例 |
|------|------|------|
| Zero-shot | 不提供示例 | "将以下文本翻译为英文：..." |
| Few-shot | 提供少量示例 | 输入→输出对 × 3 + 待处理输入 |
| Chain-of-Thought | 分步推理 | "请一步步思考..." |
| Tree-of-Thought | 多分支探索 | 生成多个推理路径，择优 |
| Self-Consistency | 多次采样投票 | 多次 CoT 推理，取多数结果 |
| ReAct | 推理+行动交替 | 思考→行动→观察→思考... |

## 结构化 Prompt 模板

```
## 角色
你是一个专业的 [领域] 专家。

## 任务
[具体任务描述]

## 输入格式
[输入数据格式说明]

## 输出格式
[期望输出格式，如 JSON]

## 约束
- [约束条件1]
- [约束条件2]

## 示例
输入：[示例输入]
输出：[示例输出]
```

## 高级技巧

- **System Prompt** — 设定全局行为规则
- **JSON Mode / Structured Output** — 约束输出格式
- **长上下文管理** — 分块摘要 / 滑动窗口
- **Prompt 缓存** — 相同前缀复用 KV Cache
- **对抗性 Prompt** — Prompt 注入防御
