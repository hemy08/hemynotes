# 可视化

> Matplotlib / Seaborn / Plotly

## 核心

- `plt.subplots` — 子图布局
- `sns.heatmap` — 热力图
- `sns.pairplot` — 特征对图
- `sns.boxplot` / `sns.violinplot` — 分布图
- `plt.scatter` / `plt.plot` — 散点图与折线图

## 进阶

- `FuncAnimation` — 动画
- `plotly` — 交互式图表
- `wandb` — 训练过程可视化
- `tensorboard` — TensorFlow/PyTorch 训练可视化
